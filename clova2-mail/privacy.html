Privacy Policy

Last updated: June 12, 2026

This Privacy Policy describes how the Clova2Mail Chrome extension ("Clova2Mail", "we", "our") handles your information. Clova2Mail integrates Naver CLOVA Note with Gmail, allowing you to compose and send Gmail emails from your CLOVA Note transcription results.

1. Google User Data We Access

Clova2Mail uses Google OAuth 2.0 to access the following Google API scopes:

Scope Purpose
https://www.googleapis.com/auth/gmail.send Used solely to send emails that you explicitly compose from your CLOVA Note transcription results. The extension cannot read, modify, or delete any of your existing emails.
https://www.googleapis.com/auth/userinfo.email Used to identify the signed-in Google account and display which account will be used to send emails.

2. How We Use Google User Data

Google user data is used only to provide the user-facing feature described above: sending an email from your Gmail account when you click "Send" in the extension. An email is sent only as a result of your explicit action. We do not use Google user data for advertising, profiling, market research, or any purpose unrelated to the extension's core functionality.

3. Data Storage and Retention

All processing happens locally in your browser. We do not operate any backend server, and no Google user data (including email content, recipients, or your email address) is transmitted to, stored on, or retained by any external server. Your OAuth token is managed by Chrome's identity system within your browser. User preferences may be stored locally via the Chrome storage API and never leave your device.

4. Data Sharing

We do not sell, transfer, or share Google user data with any third party. The extension does not integrate with any third-party analytics or advertising services. Data is transmitted only to Google's Gmail API for the purpose of sending the email you composed.

5. Limited Use Disclosure

Clova2Mail's use and transfer of information received from Google APIs to any other app will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

6. Security

Because no Google user data is stored on external servers, exposure risk is minimized by design. OAuth tokens are handled by the Chrome browser's built-in identity mechanisms and are never written to disk by the extension or shared with any external service.

7. Revoking Access and Data Deletion

You can revoke Clova2Mail's access to your Google account at any time at https://myaccount.google.com/permissions. Uninstalling the extension removes all locally stored preferences. Since we store no data on servers, there is no server-side data to delete.

8. Changes to This Policy

We may update this Privacy Policy from time to time. Changes will be reflected on this page with an updated revision date.
